GitHub Pages публикует main, папку /docs. Размещение и адрес бесплатные.

build.py создаёт HTML из шаблона и документов приложения. CSS хранится в docs/style.css.
Русские юридические документы берутся из docs приложения без редакционных примечаний. Готовые английские и вьетнамские переводы Claude скопированы из assets/legal/legal.en.json и legal.vi.json приложения в legal/en.json и legal/vi.json сайта. Содержание переводов не переписывалось. При обновлении документов приложения нужно обновить эти копии, затем запустить build.py и check.py.

Сайт доступен на трёх языках: русский в корне, английский /en/, вьетнамский /vi/. На каждой из 12 страниц есть переключатель языка, ведущий к тому же документу. Русские публичные адреса сохранены. Язык выбирается ссылками, без cookies и принудительной переадресации.

18 октября 2026: на главных страницах добавлены анимации появления и интерактивная история «один день» (story.py, docs/motion.css, docs/motion.js). Прокрутка или кнопки переключают три состояния демонстрации: исходные цифры, расход 350 ₽, накопление 1 500 ₽. Все суммы вымышлены. Анимация не обращается в сеть и не сохраняет данные. Учитывается prefers-reduced-motion; без JavaScript остаётся статическое содержимое. Документы и поддержка анимационный код не загружают. Не менять порядок script/link в мультиязычном генераторе без проверки относительных путей en/vi.
